# 🎬 MovieMate - Cinema Booking Application

## 📌 Project Overview

**MovieMate** is a modern and responsive movie booking web application that allows users to browse movies, select seats, and simulate payments. The application is designed with a clean UI and smooth user experience using modern frontend technologies.

---

## 🚀 Features

* 🎥 Browse available movies
* 🪑 Interactive seat selection system
* 💳 Payment simulation using Razorpay
* ⚡ Fast and responsive UI
* 🔥 Smooth animations using Framer Motion
* 🔔 Notifications with React Hot Toast

---

## 🛠️ Tech Stack

### Frontend

* React.js
* Vite
* Tailwind CSS

### Libraries & Tools

* React Router DOM
* Framer Motion
* Lucide React Icons
* Razorpay (Payment Integration)
* React Hot Toast

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Bholaa2002/MovieMate.git
cd MovieMate
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Run the Application

```bash
npm run dev
```

### 4️⃣ Build for Production

```bash
npm run build
```

---

## 💳 Payment Integration

This project uses **Razorpay** for payment simulation.
Make sure to configure your API keys in the `.env` file:

```
VITE_RAZORPAY_KEY=your_key_here
```
